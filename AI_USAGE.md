# AI Usage Declaration

## AI Tools Used

The following AI assistant was used during the development of this project:

- ChatGPT (OpenAI)

---

## Purpose of AI Assistance

AI was used as a programming and learning assistant throughout the assignment. Specifically, it was used for:

- Brainstorming data cleaning strategies.
- Discussing feature engineering approaches.
- Explaining machine learning concepts and algorithms.
- Assisting with the implementation and debugging of Logistic Regression and Random Forest models.
- Reviewing and improving the design of the Outreach Assistant.
- Refining natural-language prediction explanations.
- Improving project documentation, including the README and project report.
- Reviewing code for readability, organization, and best practices.

---

## Author Responsibility

All key technical decisions were made by the author, including:

- Data cleaning and preprocessing decisions.
- Feature selection and engineering.
- Identification and exclusion of the `legacy_propensity_score` leakage feature.
- Fairness considerations and responsible AI safeguards.
- Model training, evaluation, and final model selection.
- Outreach Assistant functionality and behavior.
- Validation, testing, and interpretation of all results.

All generated code and documentation were reviewed, modified where necessary, tested, and validated before inclusion in the final submission.

---

## Statement

AI assistance was used to improve productivity and support the development process. The final implementation, analysis, evaluation, and submitted work represent the author's reviewed and validated solution.
